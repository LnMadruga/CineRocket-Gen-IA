1. O que é o OpenRouter

O OpenRouter é um roteador de LLMs. Ele não treina modelos — agrega dezenas deles (Google, Meta, NVIDIA, etc.) atrás de uma única API compatível com a da OpenAI.

Você cria uma conta, gera uma chave, e chama qualquer modelo trocando apenas o campo model. Para este treinamento usaremos modelos gratuitos, sem necessidade de cartão de crédito.

2. Criando conta e chave de API

  1. Acesse openrouter.ai e crie uma conta (Google, GitHub ou e-mail).
  2. Vá em openrouter.ai/keys e clique em Create Key.
  3. Copie a chave gerada (começa com sk-or-v1-...). Ela só aparece uma vez.
  4. Guarde essa chave. Você usará ela para autenticar suas chamadas à API.

3. Modelos gratuitos FREE

O modelo padrão recomendado é o openrouter/free — um router que seleciona automaticamente um modelo gratuito disponível no momento. É a forma mais simples de começar.

Endpoint e configuração

ParâmetroValor
Base URLhttps://openrouter.ai/api/v1
Modelopenrouter/free
Auth headerAuthorization: Bearer sk-or-v1-SUA_CHAVE

Se quiser escolher um modelo específico, alguns modelos gratuitos de chat disponíveis:

ModeloContextoObservação

A lista completa está em openrouter.ai/models?q=:free.

4. O modelo não respondeu?

Se você recebeu um erro 429, não se preocupe — provavelmente não é um problema com a sua chave.

Modelos :free compartilham um pool de capacidade. Se muitas pessoas usam ao mesmo tempo, o provider fica temporariamente lotado. Isso é diferente de ter esgotado sua cota diária.

O que fazer: teste outro modelo gratuito. Troque o campo model na sua chamada.

5. Rastreio de uso e limites IMPORTANTE

Limites do free tier

Sem créditos comprados2050
Comprou ≥ US$10 alguma vez201.000
Requests que falham também contam no limite do dia. Se você receber um 429 e ficar re-tentando imediatamente, vai queimar sua cota sem obter resposta.

Como verificar sua cota

Painel web: acesse openrouter.ai/activity para ver quantas requests fez no dia.

Via API: faça um GET em https://openrouter.ai/api/v1/key com sua chave no header. O campo free_model_daily_requests retorna:

{
  "used": 12,
  "limit": 50,
  "remaining": 38
}

Quando reseta?

O contador zera à meia-noite UTC — ou seja, 21h no horário de Brasília.

Dica: antes de iterar sobre várias versões do prompt, verifique quantas requests restam. Planeje e estruture o prompt antes de disparar chamadas.

6. Erros comuns

CódigoCausaO que fazer
401 Chave inválida ou ausente Confirme que a chave começa com sk-or-v1- e está sendo enviada corretamente
429 + upstream_provider Pool do provider lotado Não é sua cota. Teste outro modelo gratuito
429 (sem provider) Cota do dia atingida (50 req) Verifique em activity. Aguarde o reset às 21h (BRT)
402 Saldo negativo na conta Modelos :free não cobram. Se apareceu, verifique se o saldo da conta não está negativo
